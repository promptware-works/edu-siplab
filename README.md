# SIPLab

Build and test a SIP PBX — then extend it with an **AI SIP Test Engineer**.

Student groups design, install, operate, and test a small open-source SIP
IP-PBX. They then add a prompt-defined AI SIP Test Engineer: an in-chat
**Orchestrator** that follows a **Plan → Approve → Execute** protocol and
dispatches small **protocol skills** to diagnose saved packet captures of the
group's own tests, with every claim tied to a cited packet.
