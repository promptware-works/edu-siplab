# PBX setup (P1)

- `pjsip.conf`, `extensions.conf`, `rtp.conf` extracts with every `password=`
  value replaced by `[redacted]`. Endpoints use `direct_media=no`.
- `setup-notes.md` — software versions, addresses, and the steps needed to
  reproduce the setup.
- `diagram.*` — system and network diagram (image or Markdown).
- `inventory.md` — server, clients, network, and software components with
  versions; which components share a physical host.
- `registration-evidence/` — screenshots or a capture showing that the PBX runs
  and the clients register.
