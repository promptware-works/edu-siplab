# Test runs (P3)

One folder per test: `tests/<test-id>/` containing

- `copilot.md` and `claude.md` — the full chat transcript in each environment;
- `report-copilot.json`, `report-claude.json` — the saved REPORT JSON of each run;
- `validator.txt` — the output of `siplab/tools/validate_evidence.py` for each report.
